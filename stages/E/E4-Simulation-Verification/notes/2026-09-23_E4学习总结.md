# E4 学习日志｜流水灯时序逻辑初步

**日期：2026-09-23**

今天继续学习 E4，开始进入 **流水灯时序逻辑实验**。

主要完成了以下内容：

1. 编写流水灯 RTL 模块 `light.v`，加入：
   - `clk` 时钟信号
   - `rst` 复位信号
   - `count` 计数器
   - 16 位 `led` 输出
2. 理解了时序逻辑与之前组合逻辑的区别：

```
组合逻辑：
输入变化 → 输出立即变化

时序逻辑：
只有 clk 上升沿到来时 → 寄存器状态更新
```

1. 使用：

```
always @(posedge clk)
```

实现流水灯状态更新，并通过：

```
led <= {led[14:0], led[15]};
```

实现 LED 循环左移。

1. 将 `COUNT_MAX` 参数临时设置为 `3` 进行仿真，观察到：

```
0001
↓
0002
↓
0004
↓
0008
↓
0010
↓
0020
...
```

并理解了计数器：

```
0 → 1 → 2 → 3 → 0
```

每经过 4 个时钟周期，LED 移动一次。

1. 为流水灯加入 FST 波形，并使用 GTKWave 查看：

```
clk
rst
count
led
```

成功观察到时钟翻转、复位、计数器循环以及 LED 移动之间的关系。

1. 调试过程中发现 `single_cycle()` 中误写：

```
wave;
```

而不是：

```
wave();
```

导致低电平阶段没有真正记录波形，因此 GTKWave 中 `clk` 看起来一直为高。修正后波形正常。
