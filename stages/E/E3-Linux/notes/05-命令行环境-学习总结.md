# 第五部分：命令行环境学习总结

## 一、任务控制

```text
Ctrl+C       终止前台任务
Ctrl+Z       暂停前台任务
jobs         查看当前 Shell 的任务
bg %1        让任务 1 在后台继续
fg %1        把任务 1 拉回前台
command &    直接在后台运行
```

任务编号和 PID 不相同：

```text
%1       Shell 任务编号
12345    操作系统进程 PID
```

常用查看方式：

```bash
jobs -l
echo "$!"
ps -p "$pid" -o pid,ppid,stat,cmd
```

## 二、信号与 kill

```text
SIGINT     Ctrl+C 发送的中断信号
SIGTSTP    Ctrl+Z 发送的暂停信号
SIGTERM    请求程序正常退出
SIGKILL    强制终止，程序无法处理
SIGSTOP    暂停进程
SIGCONT    恢复进程
SIGHUP     终端断开信号
```

常用命令：

```bash
kill PID
kill -STOP PID
kill -CONT PID
kill -KILL PID
```

通常应先使用普通 `kill`，只有进程无法退出时再使用 `kill -KILL`。

## 三、后台任务、nohup 与 disown

```bash
command &
```

只是在后台执行，仍然属于当前 Shell。

```bash
nohup command > output.log 2>&1 &
```

让程序忽略 `SIGHUP`，适合终端关闭后继续运行。

```bash
disown %1
```

把任务从当前 Shell 的任务列表中移除，但进程继续运行。

## 四、tmux

tmux 可以保存完整终端会话，SSH 断开后仍可重新连接。

### 会话

```bash
tmux new -s study
tmux ls
tmux attach -t study
tmux kill-session -t study
```

### 常用快捷键

```text
Ctrl+b d       分离会话
Ctrl+b c       创建窗口
Ctrl+b n/p     前后切换窗口
Ctrl+b 0/1     按编号切换窗口
Ctrl+b ,       重命名窗口
Ctrl+b "       上下分屏
Ctrl+b %       左右分屏
Ctrl+b 方向键  切换 Pane
Ctrl+b z       放大或恢复 Pane
```

## 五、alias、配置文件和环境变量

### alias

```bash
alias gst='git status'
unalias gst
type gst
```

临时 alias 只在当前 Shell 中有效，写入 `~/.bashrc` 可以永久生效。

修改后：

```bash
bash -n ~/.bashrc
source ~/.bashrc
```

### 环境变量

```bash
course="ysyx"
export course
unset course
```

```text
普通变量      当前 Shell 可见
export 变量   子进程也能继承
```

### PATH

```bash
echo "$PATH" | tr ':' '\n'
command -v gcc
```

将个人脚本目录加入 PATH：

```bash
export PATH="$HOME/bin:$PATH"
```

## 六、SSH

### 远程登录和执行命令

```bash
ssh 用户名@主机
ssh 用户名@主机 'hostname; whoami'
```

### 密钥认证

客户端保存私钥：

```text
~/.ssh/id_ed25519
```

服务器保存公钥：

```text
~/.ssh/authorized_keys
```

私钥不能泄露。

### SSH 配置

```sshconfig
Host ysyx-vm
    HostName 192.168.77.138
    User liuzhilong
    Port 22
    IdentityFile ~/.ssh/id_ed25519
```

配置后可以直接：

```bash
ssh ysyx-vm
```

## 七、scp 文件传输

核心规则：

> 在哪台机器执行 `scp`，哪台机器就是“本地”。

上传文件：

```bash
scp 本地文件 用户@主机:远程路径
```

下载文件：

```bash
scp 用户@主机:远程文件 本地路径
```

传输目录：

```bash
scp -r 本地目录 用户@主机:远程路径
```

## 八、SSH 本地端口转发

```bash
ssh -N -L 9000:localhost:8000 ysyx-vm
```

含义：

```text
Windows localhost:9000
        ↓ SSH 隧道
Ubuntu localhost:8000
```

参数：

```text
-L    本地端口转发
-N    不执行远程命令
-f    认证后转到后台
```

使用 `-f` 后，SSH 已经转为后台进程，`Ctrl+C` 不能关闭它，需要找到 PID 后结束。

## 九、pgrep、pkill 与 wait

```bash
pgrep -af 'sleep 10000'
pkill -f 'sleep 10000'
```

```text
pgrep    查找进程
pkill    查找并发送信号
kill     根据 PID 或任务编号发送信号
```

等待后台任务：

```bash
sleep 5 &
pid=$!
wait "$pid"
```

`wait` 通常等待当前 Shell 启动的子进程。

## 十、kill -0 与 pidwait

```bash
kill -0 PID
```

只检查进程是否存在，不终止进程。

```text
返回 0       进程存在且有权限
返回非 0     进程不存在或没有权限
```

等待进程结束：

```bash
while kill -0 "$pid" 2>/dev/null; do
    sleep 1
done
```

其中：

```text
2              标准错误
2>/dev/null    把错误提示丢弃
```

重点：

> 重定向决定“显示什么”，退出状态决定“流程怎么走”。
