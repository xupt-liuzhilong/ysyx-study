## 一、grep：文本筛选

### 常用写法

```bash
grep 'ERROR' file
grep -n 'ERROR' file
grep -i 'error' file
grep -v 'INFO' file
grep -E 'ERROR|WARN' file
grep -oE 'user=[a-z]+' file
```

### 参数含义

- `-n`：显示行号
- `-i`：忽略大小写
- `-v`：反向筛选
- `-E`：启用扩展正则表达式
- `-o`：只输出匹配到的部分

### 统计用户名出现次数

```bash
grep -oE 'user=[a-z]+' access.log |
    cut -d'=' -f2 |
    sort |
    uniq -c |
    sort -nr
```

结果：

```text
2 bob
2 alice
1 charlie
```

其中：

- `cut`：按分隔符切割字段
- `sort`：排序，让相同内容相邻
- `uniq -c`：合并相邻重复行并计数
- `sort -nr`：按数字从大到小排序

## 二、sed：替换和提取文本

### 基础替换

```bash
sed 's/旧内容/新内容/' file
sed 's/旧内容/新内容/g' file
```

- 默认只替换每行第一个匹配
- `g` 表示替换每行全部匹配

### 捕获组

```bash
sed -En 's/.*user=([a-z]+).*/\1/p' access.log
```

关键点：

- `-E`：启用扩展正则
- `-n`：关闭默认输出
- `()`：捕获内容
- `\1`、`\2`：引用第一个、第二个捕获组
- `p`：打印成功匹配的行

### 原地修改

```bash
sed -i 's/ERROR/FAIL/g' file
sed -i.bak 's/FAIL/ERROR/g' file
```

第二条命令会额外保留修改前的 `.bak` 备份。

### 不能这样修改原文件

```bash
sed 's/ERROR/FAIL/g' file > file
```

原因：Shell 会在 `sed` 读取之前先清空输出文件。

安全方案：

```bash
sed 's/ERROR/FAIL/g' file > file.tmp &&
mv file.tmp file
```

## 三、awk：按列处理和统计

### 常用字段

```text
$0    整行
$1    第 1 列
$2    第 2 列
$NF   最后一列
NF    当前行字段数
NR    当前行号
```

### 基本结构

```bash
awk '条件 {动作}' 文件
```

例如：

```bash
awk '$2 == "ERROR" {print NR, $3}' access.log
```

### 求和和平均值

```bash
awk '{sum += $2} END {print sum}' latency.log
```

```bash
awk '{sum += $2} END {
    printf "平均延迟：%.2f ms\n", sum / NR
}' latency.log
```

### 分组统计

```bash
awk '{
    sum[$1] += $2
    count[$1]++
}
END {
    for (user in sum) {
        printf "%s：%.2f ms\n", user, sum[user] / count[user]
    }
}' latency.log
```

结果：

```text
charlie：300.00 ms
bob：200.00 ms
alice：100.00 ms
```

### split 拆分字段

```bash
awk '$4 ~ /^user=/ {
    split($4, parts, "=")
    print parts[2]
}' access.log
```

## 四、正则表达式

### 常见符号

```text
^             行首
$             行尾
.             任意单个字符
\.            普通点号
[abc]         a、b、c 中任选一个
[^abc]        排除 a、b、c
[0-9]         任意数字
*             零次或多次
+             一次或多次
?             零次或一次
{3}           恰好重复三次
{1,2}         重复一到两次
(...)         分组
|             或
[[:space:]]   空白字符
```

### 已练习的表达式

```regex
^abd456$
^abc
[0-9]{3}$
^hello\.txt$
^gr(a|e)y$
^file[0-9]{3}\.txt$
^hello[[:space:]]+world$
^ab+c$
```

## 五、正式练习

### 1. 筛选至少含三个 a 的单词

```bash
tr '[:upper:]' '[:lower:]' < /usr/share/dict/words |
    grep -E '^([^a]*a){3}.*$' |
    grep -v "'s$"
```

当前词典中符合条件的单词数量：

```text
854
```

### 2. 统计最后两个字母

```bash
grep -oE '[a-z]{2}$' three_a_words.txt |
    sort |
    uniq -c |
    sort -nr |
    head -n 3
```

### 3. 生成全部两字母组合

```bash
printf '%s\n' {a..z}{a..z} > all.txt
```

一共有：

```text
676
```

种组合。

### 4. 找未出现的组合

```bash
comm -23 all.txt occurrence.txt > missing_pairs.txt
```

思路：

```text
全部组合 - 实际出现组合 = 从未出现的组合
```

## 六、今天最重要的理解

```text
grep    负责筛选
sed     负责替换和提取
awk     负责按列计算和统计
sort    负责排序
uniq    负责去重和计数
wc      负责统计数量
|       负责传递数据
```

复杂命令不需要整条背下来。正确方法是：

1. 先理解每个工具负责什么。
2. 把长管道拆成几步。
3. 每增加一个命令，就检查一次输出。
4. 忘记参数时用 `man` 或 `--help` 查询。
