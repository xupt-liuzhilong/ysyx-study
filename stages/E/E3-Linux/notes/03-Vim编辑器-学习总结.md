## 一、Vim 的模式

Vim 主要模式：

```text
普通模式      执行移动、删除、复制等操作
插入模式      输入文本
可视模式      选择文本
命令行模式    保存、退出、搜索替换等
```

常见切换：

```text
i       进入插入模式
a       在光标后进入插入模式
I       在行首进入插入模式
A       在行尾进入插入模式
Esc     返回普通模式
:       进入命令行模式
```

---

## 二、基本移动

```text
h    左
j    下
k    上
l    右
```

按单词移动：

```text
w    下一个单词开头
b    上一个单词开头
e    当前或下一个单词结尾
```

行内移动：

```text
0    当前行最左侧
^    当前行第一个非空字符
$    当前行末尾
```

文件内移动：

```text
gg   文件开头
G    文件末尾
```

---

## 三、删除与修改

删除：

```text
x     删除光标下字符
dw    删除到下一个单词开头
dd    删除当前行
d$    删除到行尾
D     等价于 d$
```

修改：

```text
cw    删除到下一个单词开头并进入插入模式
cc    删除整行并进入插入模式
c$    删除到行尾并进入插入模式
```

区别：

```text
d    删除后停留在普通模式
c    删除后进入插入模式
```

---

## 四、Vim 的组合思想

Vim 的核心不是死记每条命令，而是：

```text
操作符 + 移动范围
```

例如：

```text
d + w    删除一个单词
d + $    删除到行尾
c + w    修改一个单词
y + y    复制一行
```

数字可以表示重复次数：

```text
3w     向后移动三个单词
3x     删除三个字符
3dd    删除三行
```

## 五、撤销与重做

```text
u         撤销
Ctrl+r    重做
```

删除或修改错误后，可以立即使用 `u` 恢复。

## 六、复制与粘贴

复制：

```text
yy      复制当前行
3yy     复制三行
```

粘贴：

```text
p       粘贴到光标之后；整行内容粘贴到当前行下面
P       粘贴到光标之前；整行内容粘贴到当前行上面
```

## 七、搜索

向后搜索：

```vim
/关键字
```

向前搜索：

```vim
?关键字
```

搜索结果跳转：

```text
n    下一个匹配
N    上一个匹配
```

关闭高亮：

```vim
:noh
```

---

## 八、替换

替换当前行第一个匹配：

```vim
:s/旧内容/新内容/
```

替换当前行所有匹配：

```vim
:s/旧内容/新内容/g
```

替换整个文件：

```vim
:%s/旧内容/新内容/g
```

逐个确认：

```vim
:%s/旧内容/新内容/gc
```

其中：

```text
%    整个文件
s    substitute
g    当前范围内全部匹配
c    每次替换前确认
```

只匹配完整单词：

```vim
:%s/\<add\>/sum/g
```

## 十、缩进

```text
>>    当前行右缩进
<<    当前行左缩进
```

可视模式中：

```text
>     右缩进选中内容
<     左缩进选中内容
```

重新选择上一次区域：

```text
gv
```

自动缩进整个文件：

```text
gg=G
```

拆开理解：

```text
gg    文件开头
=     自动缩进
G     到文件末尾
```

## 十一、Buffer 与分屏

### Buffer

查看缓冲区：

```vim
:ls
:buffers
```

切换：

```vim
:bn
:bp
:b 编号
:b 文件名
```

### 水平分屏

```vim
:sp 文件
```

### 垂直分屏

```vim
:vsp 文件
```

### 窗口切换

```text
Ctrl+w h    左
Ctrl+w j    下
Ctrl+w k    上
Ctrl+w l    右
Ctrl+w w    循环切换
```

关闭当前窗口：

```vim
:q
```

只保留当前窗口：

```text
Ctrl+w o
```

平均分配窗口大小：

```text
Ctrl+w =
```

### 三个概念

```text
buffer    内存中已打开的文件
window    屏幕上显示 buffer 的区域
tab       一组窗口布局
```

## 十二、点命令

```text
.
```

用于重复上一次完整的文本修改。

例如：

```text
I// <Esc>
j.
j.
```

可以在连续多行开头重复添加注释。

适合：

- 连续修改相似内容
- 连续添加分号
- 重复单词替换
- 重复行内编辑

---

## 十三、宏

开始录制到寄存器 `a`：

```text
qa
```

停止录制：

```text
q
```

执行宏：

```text
@a
```

重复上一次宏：

```text
@@
```

执行三次：

```text
3@a
```

查看寄存器：

```vim
:registers a
```

宏适合重复一整套操作，`.` 更适合重复一次修改。

## 十四、多文件综合练习

同时打开：

```bash
vim main.c add.c add.h
```

查看和切换：

```vim
:ls
:bn
:bp
```

把函数名 `add` 改为 `sum`：

```vim
:%s/\<add\>/sum/g
```

保存全部：

```vim
:wa
```

退出全部：

```vim
:qa
```

编译：

```bash
gcc -Wall -Wextra -g main.c add.c -o test_add
./test_add
```

预期输出：

```text
30
```

## 十六、核心理解

```text
普通模式      负责操作
插入模式      负责输入
可视模式      负责选择
命令行模式    负责保存、退出和替换
```

Vim 的核心思想：

```text
操作符 + 移动范围
```

例如：

```text
d + w
c + $
y + y
```

需要重点熟练：

```text
w b e
0 ^ $
dw dd d$
cw cc
yy p P
u Ctrl+r
/ n N
:s :%s
v V Ctrl+v
:sp :vsp
Ctrl+w h/j/k/l
.
qa @a
```

Vim 不需要一次记住所有快捷键，应通过实际写代码逐渐形成肌肉记忆。
