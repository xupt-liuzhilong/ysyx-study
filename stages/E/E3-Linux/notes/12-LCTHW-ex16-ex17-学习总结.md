# E3-Linux Learn C The Hard Way 学习总结（Ex16-Ex17）

## Ex16：结构体与指针

结构体用于组合多个相关数据：

``` c
struct Person {
    char *name;
    int age;
};
```

访问：

普通变量：

``` c
person.age;
```

指针：

``` c
person_ptr->age;
```

等价：

``` c
(*person_ptr).age;
```

------------------------------------------------------------------------

## 动态内存管理

申请：

``` c
malloc()
```

释放：

``` c
free()
```

原则：

> 谁申请，谁释放。

否则会产生内存泄漏。
