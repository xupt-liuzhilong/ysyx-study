## 关键实验

### 1. 未初始化变量

使用：

```bash
gcc -Wall -Wextra -g ex4.c -o ex4
valgrind ./ex4
```

观察到未初始化值相关错误。修复初始化后：

```text
ERROR SUMMARY: 0 errors from 0 contexts
```

### 2. 字符串结尾

```c
char demo[] = "ZedX";
demo[3] = '\0';
printf("%s\n", demo);
```

输出：

```text
Zed
```

说明 `%s` 从首地址开始，一直读取到 `\0` 为止。

### 3. argv

```bash
./ex10 hello ysyx linux
```

对应：

```text
argc = 4
argv[0] = ./ex10
argv[1] = hello
argv[2] = ysyx
argv[3] = linux
argv[4] = NULL
```

并验证：

```c
argv[1] == &argv[1][0]
```

### 4. switch fall-through

删除一个 `break` 后，GCC 给出：

```text
warning: this statement may fall through
```

程序对字母 `e` 连续执行了 `E` 和 `I` 两段代码，说明进入某个 `case` 后如果没有 `break`，会继续向下执行。
