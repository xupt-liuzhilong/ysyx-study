## 今日重点

### Makefile

通过：

```bash

```

观察到源文件时间变化后会触发重新编译，理解了 Make 基于依赖和时间戳判断是否需要重新构建。

### printf

重点掌握：

```c
printf("PC = 0x%08x\n", pc);
```

理解 `%08x` 表示十六进制固定 8 位，不足补 0。

### GDB

练习：

```text
break
run
next
step
print
info args
info locals
bt
frame
finish
continue
```

并通过空指针程序实际定位了 `SIGSEGV`。

调试过程：

```text
程序崩溃
→ GDB run
→ bt 查看调用链
→ list 看源码
→ print p 发现 p = 0x0
→ 确认空指针解引用
→ 修改代码
→ 重新编译运行验证
```

## 今日遇到的问题

1. 一开始打印 PC 时只用了 `%x`，随后注意到题目要求固定 8 位、不足补 0，改成 `%08x`。
2. 理解了 GDB 停在某一行时，这一行通常还没有真正执行。
3. `continue` 只是继续运行程序，并不会修复导致段错误的根本问题。
