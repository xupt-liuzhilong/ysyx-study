# 2026-08-13 学习日志

## 今日学习内容

今天继续推进一生一芯 E3-Linux，学习 `Learn C The Hard Way` 的 ex05 和 ex06。

### ex05：C 运算符与位运算

复习了：

- 算术运算：`+ - * / %`
- 比较运算：`> < >= <= == !=`
- 逻辑运算：`&& || !`
- 位运算：`& | ^ ~ << >>`

重点理解：

```c
inst & 0xff
```

表示保留整数最低 8 位，与大小端无关。

随后通过：

```c
unsigned char *p = (unsigned char *)&inst;
```

按字节观察内存，进一步区分了：

- 位运算：处理整数值本身
- 大小端：影响多字节数据在内存中的排列顺序

继续练习了掩码和移位：

```c
(value >> start) & mask
```

并理解：

```c
(inst >> 15) & 0x1f
```

会先把原来的 bit `[19:15]` 移到最低 5 位，再通过 `0x1f` 保留这 5 位，因此可以提取指定字段。

这部分已经开始和后续 RISC-V 指令译码建立联系。

### ex06：C 基础语法复盘

复习了：

- `if / else`
- `for`
- `continue`
- `break`
- `switch / case`
- `while`
- `do-while`

通过练习确认：

```text
continue  -> 跳过本轮循环剩余部分
break     -> 直接结束当前循环或 switch
```

重点实验：

```c
if (a = 5)
```

使用：

```bash
gcc -Wall -Wextra syntax.c -o syntax
```

时，GCC 给出了 assignment used as truth value 的 warning。

进一步明确：

```text
=   赋值
==  比较
```

同时验证了：

```text
while      可能一次都不执行
do-while   至少执行一次
```
