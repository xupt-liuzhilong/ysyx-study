# Extra C Exercises

该目录保存 2026 年 8 月学习过程中，在完全对齐一生一芯指定版
《Learn C the Hard Way》之前完成的补充练习。

这些内容不对应官方 Exercise 编号，但仍作为 C / Linux / 系统编程
能力补充保留。

- `01_gdb`：GDB 基础调试
- `02_bitwise_and_instruction`：位运算与 RISC-V 指令字段提取
- `03_control_flow`：C 控制流与编译器警告
- `04_integer_types`：定宽整数、有符号/无符号、整数溢出
- `05_args_and_if`：argc/argv、条件判断
- `06_while_and_null`：while、布尔表达式、NULL 与哨兵数组
